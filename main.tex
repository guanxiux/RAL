\title{\sysname: Closing the Sparsity-to-Speedup Gap in Masked Convolution with Worklist-Driven Execution}
\author{Anonymous Authors}

\begin{abstract}
% v17 (ISCA framing, 2026-11-10)
Masked convolution promises lower latency by computing only
positions an upstream policy marks active, yet existing paths keep either
throughput (tile skipping) or useful-compute ratio (gather-scatter), never
both, failing to turn sparsity into proportional speedup.
Contrary to the expectation that scattered work breaks dense efficiency, we
find that restricting a dense tiled pipeline to scattered positions
largely preserves per-tile throughput: irregularity is confined to row-level
indirection outside the reduction loop, leaving channel-contiguous access and
weight-tile reuse identical to dense. We therefore present
\sysname, which drives the unchanged dense pipeline with an active-output
worklist. The worklist brings two costs
dense execution never pays. Construction cost stays fixed per layer shape as
compute shrinks with the active ratio, so \sysname builds the worklist in one
mask-space pass and reuses it across compatible operators. The worklist length, visible only on
the device, varies per frame and layer and shifts the best tile configuration,
so \sysname performs on-device cost-aware configuration switching,
weighing each
candidate's gain against its selection cost. Across six GPUs and four workloads,
\sysname achieves a 2.20$\times$ geometric-mean latency reduction over the
fastest baseline per workload-platform pair and reduces energy by
60.8--90.1\% versus dense execution on embedded GPUs.
\end{abstract}
