\section{Conclusion}
\label{sec:conclusion}

\sysname narrows the sparsity-to-speedup gap of masked convolution with
worklist-driven tiled execution. Using output coordinates as the interface
between position selection and the dense reduction datapath, it restricts
computation to active positions at the per-tile throughput of dense execution;
with co-designed construction, reuse, and selection, what separates it from
proportional speedup is per-layer fixed cost, not lost throughput. Faster,
more energy-efficient masked convolution lets latency-critical perception,
such as a car avoiding a pedestrian, a drone dodging an obstacle, or a robot
returning a ball, react sooner within the same onboard power budget.
Lightweight GPU support for launch and for acting on device-resident values
(\S\ref{sec:eval:discussion}) would narrow the gap further.
